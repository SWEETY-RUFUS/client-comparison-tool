How matching works

  • Sheet order is preserved. Sheet 2 checks Sheet 1 first; Sheet 3 checks Sheet 1, then Sheet 2; and so on.
  • Exact Banner + Address matches are accepted.
  • Formatting differences in Banner or Address are normalized.
  • If Banner is the same/similar and Address has a normal variation such as STREET/ST, AVENUE/AVE, SUITE/STE, or a suite number, it can match.
  • If Address is the same and Banner has a meaningful variation, the tool can match it using banner similarity.
  • The first/oldest matching sheet wins.
  • Matched_Sheet is added to every valid comparison sheet and remains blank when no match is found.
  • Match_Type explains why a match was accepted.
