Global Force mapping + client-wise extract

Use one shared mapping list for every client, and one reusable sheet to extract matched IDs for any client.

  1. Download the comparison result and open it in Excel.
  2. In the Force sheet, use only columns A and B: Client_Unique_ID and PTY_LOCAL_CODE.
  3. Keep previous mapping rows. Append the next set of mappings below them; do not clear the old mappings.
  4. All client sheets use the same Force list. A matching Matched_CL_ID receives its PTY_LOCAL_CODE; unmatched/blank codes remain blank and existing codes are retained if no new mapping is found.
  5. In Matched_ID_Extract, enter any exact client worksheet name in cell B2. The sheet lists its Matched_CL_ID and PTY_LOCAL_CODE, including rows where the code is still blank.
  6. The automatic extract uses Excel 365 / Excel for the web dynamic-array functions.
🔒 Your file stays in your browser. The workbook is processed locally and is not uploaded to this website by the comparison tool.
