Comparison logic

  1. Sheet 1 is the oldest sheet and is not given a result column.
  2. Sheet 2 compares with Sheet 1.
  3. Sheet 3 compares with Sheet 1 first, then Sheet 2.
  4. Every later sheet compares with all older sheets in workbook order.
  5. If several older sheets match, the earliest matching sheet is written.
  6. If there is no match, Matched_Sheet stays blank.
  7. Matching uses CL_STORE_NAME + CL_PA_LINE1.
