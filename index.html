PSU + Local Code Matching extracts and Force register

Use the two reusable extraction sheets and one permanent three-column mapping register.

  1. Download the comparison result and open it in Excel. Older utility sheets named Matched or Matched Sheet are excluded and replaced by the current PSU and Local Code Matching sheets.
  2. In the Force sheet, maintain these three columns: Client_Unique_ID, PTY_LOCAL_CODE, and Source_Client_Sheet.
  3. Client_Unique_ID is matched against Matched_CL_ID across all client sheets. PTY_LOCAL_CODE is the code to populate. Source_Client_Sheet records where the mapping came from.
  4. Keep previous mapping rows and append new mappings below them. Existing entries, including rows with a blank code, are carried forward when you run the tool again.
  5. In PSU, enter an exact client worksheet name in cell B2. It returns Matched_CL_ID, PTY_LOCAL_CODE, and Source_Client_Sheet, including rows where the code is blank.
  6. In Local Code Matching, enter an exact client worksheet name in cell B2. It returns the source client sheet name, the actual source-row CL_ID, and its PTY_LOCAL_CODE.
  7. The two automatic extracts use Excel 365 / Excel for the web dynamic-array functions.
🔒 Your file stays in your browser. The workbook is processed locally and is not uploaded to this website by the comparison tool.
